05 · When It Fails

실패 시 대처와 Mac 조회

증상 (항목)흔한 원인대처
본문이 비어 온다 (I·J·M)해당 앱 알림 미리보기가 “항상”이 아님설정 → 알림 → 카카오톡·Instagram → 미리보기 “항상”. K 뒤에 복구했는지
잠금인데 locked=false (J·Q)잠근 뒤 15초를 기다리지 않음잠그고 15초 이상 기다린 뒤 발송. 잠근 직후 약 10초는 데이터 보호가 아직 풀려 있다
trace가 안 올라온다 (전 항목)trace 세션 없음, 또는 앱을 열지 않음앱 trace 섹션이 “세션 없음”이면 E 재실행. “대기 n건”이 줄지 않으면 네트워크와 trace upload fail status= 로그
devices 행이 없다 · 푸시가 안 온다 (F·U–W)앱에 등록 코드 없음(현재 코드), 또는 환경 불일치등록 코드를 넣은 새 TestFlight 빌드 전엔 U–W 보류. 행이 있으면 apns_env가 production인지, 응답 envRetries·reasons
업로드가 안 온다 (AC–AE)업로드 서버 주소·로컬 네트워크 권한·방화벽·다른 Wi-Fi앱 “업로드 서버” 값이 Mac LAN IP:포트인지, D 허용, Mac 방화벽에서 deno 허용, iPhone Safari로 /received 열어 도달 확인

Mac 조회는 poc/server에서 한다. 셸 함수 하나를 정의해 두고 세션 내내 쓴다. 토큰·본문 조회 금지(AGENTS §7).

cd poc/server
Q() { deno run --allow-net --allow-env --allow-read --env-file=.env scripts/sql.ts "$@"; }
# 1. 세션 요약 — 이벤트별 건수·elapsed_ms p50/p95·잠금·백그라운드 건수 ($1·$2 = 세션 시작·끝, ISO)
Q "select event, count(*)::int n,
     percentile_cont(0.5) within group (order by (fields->>'elapsed_ms')::numeric) p50_ms,
     percentile_cont(0.95) within group (order by (fields->>'elapsed_ms')::numeric) p95_ms,
     count(*) filter (where (fields->>'locked')::boolean)::int locked,
     count(*) filter (where (fields->>'bg')::boolean)::int bg
   from poc_traces where at between \$1 and \$2 group by event order by event" \
  "<세션 시작>" "<세션 끝>"
# 2. 특정 이벤트 — 예: PoC-1 인텐트 발화 최근 20건 (I–O, T)
Q "select at, fields->>'source' source, fields->>'text_len' text_len, fields->>'locked' locked
   from poc_traces where event = 'poc1.intent_fired' order by at desc limit 20"
# 3. 토큰 등록 확인 (F) — U–W 발송에 쓸 device_id
Q "select device_id, apns_env, build, last_seen_at from devices order by last_seen_at desc limit 3"

세션 뒤 정리(판정 기록을 옮긴 뒤): Q "delete from poc_traces where device_id = \$1" "<device_id>". results.md 근거 한 줄 형식은 기존 절차서 “Record” 절을 따른다.
