ERURI 단축어 따라하기

문자·카카오톡·Slack 알림이 오면 ERURI 가 알아서 챙기게 만들어요. 자동화를 두 개 만들어요: 문자용 하나, 그 밖의 앱용 하나. 번호를 순서대로 따라 하면 되고, 10분쯤 걸려요.

시작하기 전에: ERURI 앱을 한 번 열었다가 닫아 주세요.

왜 두 개냐면: 알림으로 받으면 긴 문자가 255자쯤에서 잘려요. 문자는 문자 자동화로 따로 받아야 끝까지 와요.

1. 문자 자동화 만들기 1 ~ 4

사진 준비 중
단축어 앱 → 자동화 → 메시지
  1. 1단축어 앱을 열고 맨 아래 자동화 → 오른쪽 위 ＋ → 목록에서 메시지를 눌러요.
  2. 2메시지에 다음을 포함을 켜고 빈칸에 띄어쓰기 한 번만 쳐요. 조건을 비워 둘 수 없어서 이렇게 해요. 보낸 사람은 고르지 않아요.
  3. 3즉시 실행(또는 실행 묻지 않기)을 골라요.
  4. 4단축어 고르는 목록이 나오면 새로운 빈 자동화를 누르고, 아래 검색 칸에 비서에 저장을 쳐서 나온 비서에 저장을 눌러요.

목록에 있는 단축어를 고르면 안 돼요. 그러면 보낸 사람만 오고 내용이 안 와요. 꼭 새로운 빈 자동화를 눌러요.

  1. 7본문 칸에 생긴 파란 단축어 입력 글자를 한 번 더 눌러요. 나온 목록에서 내용을 골라요. 파란 글자가 내용으로 바뀌면 돼요.
  2. 8발신자 칸도 똑같이 해요: 칸 누르기 → 단축어 입력 → 파란 글자 다시 누르기 → 보낸 사람 고르기. 그리고 출처 칸의 NOTIFICATION 을 지우고 MESSAGES 를 쳐요(칸이 안 보이면 동작 아래 화살표를 펼쳐요).
  3. 9실행 시 보기 스위치를 꺼요(초록색 → 회색). 오른쪽 위 완료(또는 ✓)를 눌러 저장해요.

사진은 비슷한 화면이에요. 문자 자동화는 파란 글자가 내용, 보낸 사람 으로 보이고 출처가 MESSAGES 면 잘 된 거예요.

회색 ✕ 표시: 맨 위 흐린 입력 없음 글자가 보여도 누르지 마세요. 눌러도 고를 게 없는 다른 화면으로 가요. 갔다면 ‹ 로 돌아오면 돼요.

문자 자동화는 문자가 올 때마다 화면 위에 "자동화 실행" 알림이 떠요. 지금 iOS 에는 이걸 끄는 설정이 없어요. ERURI 가 문자를 챙기고 있다는 표시로 봐 주세요.

3. 알림 자동화 만들기 10 ~ 13

사진 준비 중
단축어 앱 → 자동화 → 알림
  1. 10자동화 → 오른쪽 위 ＋ → 목록에서 알림을 눌러요. (목록 아래쪽에 있어요)
  2. 11앱 선택에서 카카오톡·Slack(택배·쇼핑·은행 앱도 좋아요)을 여러 개 한꺼번에 체크해요. 메시지 앱은 체크하지 않아요 — 문자는 1번 자동화가 받아요. "모든 앱" 은 없어요.
  3. 12실행 묻지 않기를 골라요(실행 시 알림 스위치가 보이면 꺼요). 조건을 넣으라고 하면 빈칸에 띄어쓰기 한 번만 쳐요. 그다음 새로운 빈 자동화 → 비서에 저장을 눌러요.
  4. 135 ~ 9 처럼 칸을 채워요. 이번엔 본문=내용, 제목=제목, 앱 이름=앱, 발신자=보낸 사람. 출처는 NOTIFICATION 그대로 둬요. 실행 시 보기 끄고 완료.

메시지 앱을 여기에도 체크하면 문자 하나가 두 줄로 들어와요. 메시지 앱은 꼭 빼요.

4. 잘 되는지 보기 14

사진 준비 중
ERURI 큐 목록
  1. 14가게·택배 문자 하나와 카카오톡 알림 하나를 받고, 15초 뒤에 ERURI 앱을 열어요. 큐 목록에 새 줄이 각각 생겼으면 성공이에요.

연락처에 있는 사람이 보낸 문자는 일부러 저장하지 않아요. 큐에 안 보여도 정상이에요.

띄어쓰기가 없는 아주 짧은 문자("네", "ㅇㅋ" 같은)는 문자 자동화 조건에 안 걸려서 오지 않아요. 알림이 뜨지 않는 앱 알림(집중 모드, 묶음 알림)도 빠질 수 있어요. 하나에 두 줄씩 생기면 예전 자동화(메시지 앱을 넣은 알림 자동화)가 남아 있는 거예요. 자동화 탭에서 알림 자동화의 앱 선택에서 메시지를 빼거나, 옛 자동화를 왼쪽으로 밀어 지워요.

공유 단축어 파일(AirDrop)을 받았다면

받은 "ERURI에 저장" 단축어는 공유 시트에서 글을 ERURI 로 보낼 때만 써요. 자동화에는 쓰지 않아요. 자동화에서 이 단축어를 고르면 내용이 안 오니까, 자동화는 꼭 위의 새로운 빈 자동화 방법으로 만들어요.

iOS 26 이하를 쓰고 있다면

화면이 많이 달라요. 이 안내는 iOS 27 기준이에요. 가능하면 iOS 27 로 업데이트해 주세요.
