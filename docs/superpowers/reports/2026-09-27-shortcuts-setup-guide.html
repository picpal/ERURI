00 · 이유

왜 이 설정이 필요한가

ERURI 는 문자·카톡 알림 속 예약·배송·결제 소식을 모아 정리해 주는 비서입니다. 그런데 iOS 는 앱이 다른 앱의 문자나 알림을 읽지 못하게 막아 두었고, 앱이 사용자 대신 설정을 만들어 줄 수도 없습니다. 그래서 iPhone 기본 앱인 단축어에서 "이런 알림이 오면 ERURI 에 넘겨라" 라는 규칙을 사용자가 직접 한 번 만들어야 합니다.

01 · 준비

준비물

① ERURI PoC 설치

초대 메일의 링크로 TestFlightApple 의 시험판 앱 배포 앱를 설치하고, TestFlight 안에서 ERURI PoC 를 설치합니다. 설치 후 ERURI 를 한 번 열어 두세요. 한 번 열어야 단축어 앱이 ERURI 의 동작을 찾을 수 있습니다.

② 알림 허용

ERURI 를 처음 열 때 뜨는 알림 권한 창에서 허용을 누르세요. 놓쳤다면 설정 → 알림 → ERURI PoC 에서 알림 허용을 켭니다. 앱 안 권한 요청 (알림·캘린더·연락처) 버튼앱 코드으로 다시 요청할 수도 있습니다.

③ 단축어 앱

홈 화면에 보라·분홍색 사각형이 겹친 아이콘 단축어가 있어야 합니다. 없으면 App Store 에서 "단축어" 를 검색해 다시 받으세요(Apple 이 만든 무료 앱).

카카오톡·Instagram 알림도 받으려면 설정 → 알림 → 카카오톡(또는 Instagram) → 미리 보기 표시를 "항상" 으로 두세요iOS 27 확인 필요. 미리 보기가 꺼져 있으면 알림 속 글이 비어 있어서 ERURI 가 읽을 내용이 없습니다.

06 · FAQ

자주 묻는 질문

내 문자·알림 내용은 어디로 가나요?

먼저 iPhone 안에서 걸러집니다. 인증번호는 바로 버리고, 카드·계좌번호는 끝 4자리만 남기고 가리며, 연락처에 있는 사람이 보낸 글도 버립니다. 남은 글만 ERURI 서버로 암호화해 보내고, 원문은 90일 뒤 지웁니다. 일정·택배 같은 "정리된 사실" 만 계속 남습니다.

배터리를 많이 쓰나요?

알림 한 건마다 몇 초 도는 정도라서 크지 않을 것으로 예상하지만, 아직 실측 전입니다. 문구 조건을 넣어 대상 알림 수를 줄이는 것이 가장 확실히 아끼는 방법입니다.

잠깐 끄고 싶어요.

iOS 27 설명서에는 iOS 26 의 "이 자동화 활성화" 스위치 설명이 빠졌고, "자동화" 모음에서 켜짐·꺼짐으로 걸러 보는 방법만 있습니다iOS 27 문서. 끄는 스위치가 어디 있는지는 iOS 27 확인 필요입니다. 확실한 방법은 해당 단축어를 열고 맨 위 트리거를 제거removeiOS 27 문서하는 것입니다. 다시 켤 때는 2부 절차대로 트리거를 다시 붙입니다.

완전히 지우려면요?

단축어 모음에서 ERURI 문자·ERURI 카카오톡·ERURI 인스타·ERURI 저장을 각각 길게 누르고 삭제Delete, 이어서 단축어 삭제Delete ShortcutiOS 27 문서를 누릅니다. 같은 Apple 계정의 다른 기기에서도 함께 지워집니다. ERURI 앱을 지워도 단축어는 남아 있으니 함께 지워 주세요.

쿠팡·은행 같은 다른 앱도 추가할 수 있나요?

네. 2부 (B) 를 그대로 반복하면서 앱만 바꾸면 됩니다. 권장 문구는 주문·결제·승인입니다. 쇼핑·금융 앱은 개인 대화가 아니어서 ERURI 가 조금 더 적극적으로 받아 둡니다.

4알림 트리거가 묻지 않고 실행되는지, 개인정보 보호 스위치가 보이는지안 될 가능성이 큼(배너를 눌러야 함)문서의 자동 실행 가능 목록에 Message 는 있고 Notification 은 없음. PoC-1
5트리거가 넘기는 값의 변수 이름, 그리고 내용·보낸 사람·앱 이름·제목을 따로 꺼낼 수 있는지"단축어 입력" 과 그 속성1부 단축어의 키보드 위 막대에 "단축어 입력" 이 있음(실기기 스크린샷, 이름 끝은 잘림). 트리거 단축어 안에서의 이름과 속성 분리는 문서에 명세 없음. 스펙 §3 "미확인"
6알림 필터의 비교 방식(포함인지 일치인지), 한 필터에 단어 여러 개를 넣을 수 있는지포함 비교문서: "Message, Subtitle, Title 을 지정" 한 줄뿐
7자동화 켜기/끄기 스위치의 위치트리거 제거로 대신함iOS 27 설명서에서 "활성화 또는 비활성화" 페이지가 빠짐. 목록 필터(켜짐/꺼짐)만 있음
8트리거가 든 단축어를 링크로 공유할 때 트리거도 함께 가는지, 꺼진 채로 가는지받는 사람이 2부를 직접 함Apple: 기기마다 따로, 꺼진 채 동기화. "공유 가능" 이라는 2차 요약은 있으나 원문 확인 못 함
9"개별 동작도 자동 실행으로 설정해야 할 수 있음" 이 비서에 저장·단축어 실행에 해당하는지, 비서에 저장의 실행 시 보기(기본 켜짐)를 끄면 결과만 숨는지해당 없음 · 결과 문구만 숨음문서 주석만 있음. 실행 시 보기 스위치는 실기기 스크린샷으로 확인. 앱 인텐트는 잠금 중 실행 허용(alwaysAllowed)
10다른 단축어를 부르는 동작 이름과 입력 칸"단축어 실행"(Run Shortcut)설명서에서 동작 페이지를 찾지 못함
11동작 검색 결과에 보이는 앱 표시명"ERURI PoC"PoC-1 절차서의 시뮬레이터 기록이 근거. 실기기 TestFlight 빌드는 미확인
12ERURI 가 설치되지 않은 상태에서 링크를 가져올 때 화면"비서에 저장" 이 비어 보임추정
13카카오톡·Instagram 알림 설정의 "미리 보기 표시" 문구, "자동화" 모음 필터 문구(켜짐/꺼짐)현재 적은 대로필터는 영문 문서(Turned On/Off)만 있음. 미리 보기는 단축어 설명서 범위 밖
