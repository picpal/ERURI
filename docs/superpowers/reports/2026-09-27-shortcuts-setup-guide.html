00 · 이유

왜 이 설정이 필요한가

ERURI 는 문자·카톡 알림 속 예약·배송·결제 소식을 모아 정리해 주는 비서입니다. 그런데 iOS 는 다른 앱의 문자나 알림을 앱이 몰래 읽지 못하게 막아 두었고, 앱이 대신 설정을 만들어 줄 수도 없습니다. 그래서 iPhone 기본 앱인 단축어에서 "이런 알림이 오면 ERURI 에 넘겨라" 라는 규칙을 사용자가 직접 한 번 만들어야 합니다.

01 · 준비

준비물

① ERURI PoC 설치

초대 메일의 링크로 TestFlightApple 의 시험판 앱 배포 앱를 설치하고, TestFlight 안에서 ERURI PoC 를 설치합니다. 설치 후 ERURI 를 한 번 열어 두세요. 열어야 단축어 앱이 ERURI 의 동작을 알아봅니다.

② 알림 허용

ERURI 를 처음 열 때 뜨는 알림 권한 창에서 허용. 놓쳤다면 설정 → 알림 → ERURI PoC → 알림 허용 켜기. 앱 안 권한 요청 (알림·캘린더·연락처) 버튼앱 코드으로 다시 요청할 수도 있습니다.

③ 단축어 앱

홈 화면에 보라·분홍색 겹친 사각형 아이콘 단축어가 있어야 합니다. 없으면 App Store 에서 "단축어" 를 검색해 다시 받으세요(Apple 이 만든 무료 앱).

카카오톡·Instagram 알림도 받으려면 설정 → 알림 → 카카오톡(또는 Instagram) → 미리 보기 표시를 "항상" 으로 두세요비슷한 이름. 미리 보기가 꺼져 있으면 알림 속 글이 비어서 ERURI 가 읽을 게 없습니다.

04 · 2부 (앱마다 한 번)

2부: 자동화 만들기

자동화"○○ 가 일어나면 △△ 를 해라" 라는 규칙. 사람이 누르지 않아도 iPhone 이 알아서 실행. 문자·카카오톡·Instagram 세 가지를 각각 만듭니다. 필요한 것만 만들어도 됩니다.

공유 링크로 단축어를 받은 사람도 이 2부는 직접 해야 합니다. 자동화는 링크로 옮겨지지 않습니다.

06 · FAQ

자주 묻는 질문

내 문자·알림 내용은 어디로 가나요?

먼저 iPhone 안에서 걸러집니다. 인증번호는 바로 버리고, 카드·계좌번호는 끝 4자리만 남기고 가리며, 연락처에 있는 사람이 보낸 글도 버립니다. 남은 글만 ERURI 서버로 암호화해 보내고, 원문은 90일 뒤 지웁니다. 일정·택배 같은 "정리된 사실" 만 계속 남습니다.

배터리를 많이 쓰나요?

알림 한 건마다 몇 초 도는 정도라 크지 않을 것으로 예상하지만, 아직 실측 전입니다. 문구 조건을 넣어 대상 알림 수를 줄이면 가장 확실히 아낄 수 있습니다.

잠깐 끄고 싶어요.

단축어 → 자동화 → 끌 항목 탭 → 이 자동화 활성화 끄기 → 완료Apple 문서. 다시 켤 때도 같은 곳입니다.

완전히 지우려면요?

자동화 탭에서 항목을 왼쪽으로 쓸어 삭제비슷한 이름. 단축어 탭의 "ERURI 저장" 은 타일을 길게 눌러 삭제비슷한 이름. ERURI 앱을 지워도 자동화는 남아 있으니 함께 지워 주세요.

쿠팡·은행 같은 다른 앱도 추가할 수 있나요?

네. 2부 (B) 를 그대로 반복하고 앱만 바꾸면 됩니다. 권장 문구: 주문·결제·승인. 쇼핑·금융 앱은 개인 대화가 아니라서 ERURI 가 조금 더 적극적으로 받아 둡니다.

#항목이 문서의 가정근거 상태
1알림 트리거 이름·조건 항목(앱, 제목, 포함 문구)트리거 이름 "알림", 앱 선택 + 문구 조건한국어 설명서 트리거 4개 분류(이벤트·이동·커뮤니케이션·설정) 어디에도 알림 트리거 설명 없음
2알림 트리거가 묻지 않고 실행 가능한지불가하거나 배너 탭 필요할 수 있음설명서 "자동으로 실행할 수 있음" 목록에 알림 없음(메시지는 있음). 스펙 §3·PoC-1
3알림·메시지의 단축어 입력이 본문으로 넘어오는지, 앱 이름·제목·보낸 사람·내용을 따로 꺼낼 수 있는지단축어 입력 전체를 본문에, 메시지는 "내용"·"보낸 사람" 속성설명서에 트리거 입력 데이터 명세 없음. 스펙 §3 "미확인"
4실행 방식 선택지 실제 문구"즉시 실행" / "확인 후 실행" / "실행 시 알림"설명서 문구는 ‘실행 전에 묻기’ 끄기 → ‘묻지 않음’. 화면 문구와 다를 수 있음
5잠금 상태 실행 전용 스위치 존재 여부따로 없음, 즉시 실행이면 잠금 중에도 실행설명서 언급 없음. 앱 쪽 인텐트는 잠금 실행 허용(alwaysAllowed)
