# 네이버 캘린더를 아이폰 캘린더에 연결하기 (CalDAV)

목적: 네이버 캘린더 일정을 iOS 기본 캘린더에 붙여 두면, ERURI 0.8.0의 기기 캘린더 읽기(스펙 §9 "일정 질문과 기기 캘린더")와 겹침 확인(§10 순서 3)에 **별도 작업 없이** 반영된다. ERURI는 EventKit으로 기기에 있는 모든 캘린더를 읽기 때문이다(생일·구독 캘린더 제외).

확인 상태 표기: ✅ 확인(출처 있음) · ⚠️ 미확인(네이버 공식 고객센터 문서로는 확인 못 함 — 2026-10-01 조사).

## 1. 준비 — 네이버 앱 비밀번호

네이버 아이디·평소 비밀번호로는 연결이 실패한다. 2단계 인증을 켠 뒤 **애플리케이션 비밀번호**를 만들어 쓴다. ✅ (출처 ①②)

1. PC/모바일 웹에서 네이버 로그인 → **내정보** → **보안설정**.
2. **2단계 인증** 설정(스마트폰 네이버 앱으로 기기 인증).
3. 같은 보안설정의 2단계 인증 관리에서 **애플리케이션 비밀번호 관리** → 종류(예: iPhone/기타) 선택 → 생성. 표시된 비밀번호를 복사한다(다시 볼 수 없음 ⚠️).

## 2. 아이폰에 CalDAV 계정 추가

1. **설정 → 앱 → 캘린더 → 캘린더 계정 → 계정 추가 → 기타 → CalDAV 계정 추가**
   (iOS 17 이하: 설정 → 캘린더 → 계정 → 계정 추가 → 기타. 메뉴 이름은 iOS 버전마다 조금 다르다.) ✅ (출처 ①)
2. 입력
   | 항목 | 값 |
   |---|---|
   | 서버 | `caldav.calendar.naver.com` ✅ |
   | 사용자 이름 | 네이버 아이디(@naver.com 없이) |
   | 암호 | 1단계의 애플리케이션 비밀번호 |
   | 설명 | 예: 네이버 캘린더 |
3. **다음** → 확인 후 "캘린더" 켜고 저장.
4. 포트·SSL: 보통 손댈 필요 없음. iOS가 자동으로 SSL(443)로 접속한다 ⚠️(네이버 공식 표기 없음). 실패하면 계정 → 고급 설정에서 **SSL 사용 켬, 포트 443** 확인.
5. 캘린더 앱 → 하단 **캘린더** 목록에 네이버 캘린더들이 보이면 완료.

## 3. 네이버 예약 → 네이버 캘린더

- 이용자가 네이버 예약으로 예약했을 때 **네이버 캘린더에 자동 등록되는지는 공식 문서로 확인하지 못했다** ⚠️. 검색되는 자료는 사업자(예약 받는 쪽) 기준이며 "공식 자동 연동 없음"이라는 내용이다.
- 실기기에서 확인할 것: 네이버 앱 → 예약 상세 화면에 "캘린더에 추가/저장" 버튼이 있는지, 네이버 캘린더 앱 설정에 예약 관련 항목이 있는지. 결과는 이 문서에 적는다.
- 자동 등록이 없어도 ERURI는 **예약 확정 문자·알림톡·메일을 수집해 일정 제안**을 만든다(§5·§7) — 이 경로가 기본이다.

## 4. 동기화 주기·기본 캘린더

- iOS CalDAV는 실시간 푸시가 아니라 주기적으로 가져온다 ⚠️. 네이버에서 바꾼 일정이 늦게 보이면 캘린더 앱에서 목록을 아래로 당겨 새로고침하거나, **설정 → 앱 → 메일 → 데이터 가져오기**(가져오기 주기는 캘린더 계정에도 적용)를 더 짧게 한다.
- 과거 일정 범위: **설정 → 앱 → 캘린더 → 동기화**(기본은 최근 일부) — ERURI는 지금 앞뒤 기간만 읽으므로 기본값으로 충분하다.
- **기본 캘린더 주의**: ERURI가 제안을 "캘린더에 추가"할 때는 iOS **기본 캘린더**(`defaultCalendarForNewEvents`, 쓰기 가능해야 함 — `ios/App/NotificationActions.swift`)에 쓴다. 기본 캘린더를 네이버로 바꾸면 ERURI 일정이 네이버 캘린더(서버)에도 올라간다. iCloud에 두고 싶으면 **설정 → 앱 → 캘린더 → 기본 캘린더**를 iCloud로 유지한다.

## 5. ERURI에서 확인

1. ERURI 설정에서 캘린더 **전체 접근** 허용(추가만 허용이면 읽지 못한다).
2. 채팅: "이번 주 예약 있어?" → 답 아래 **"기기 캘린더 · 이 기간 일정 N건"** 절에 네이버 캘린더 일정도 함께 나온다(최대 5건, 32일 이내 기간).
3. 제안 카드·시트에서 같은 시간 네이버 일정이 있으면 "같은 시간에 일정 있음"/"겹쳐도 추가"로 표시된다(§10).

## 6. 연결 해제

- 아이폰: **설정 → 앱 → 캘린더 → 캘린더 계정 → (네이버 계정) → 계정 삭제**. 아이폰에서 사라질 뿐 네이버 서버 일정은 남는다.
- 네이버: 보안설정 → 애플리케이션 비밀번호 관리에서 해당 비밀번호 삭제(접근 완전 차단).
- ERURI 쪽 할 일은 없다. 다음 화면 갱신부터 그 일정이 안 보인다.

## 7. 개인정보

- 캘린더 내용은 **기기 밖으로 나가지 않는다**: 서버·LLM은 캘린더를 보지 않고, 앱은 읽은 일정을 화면에만 쓴다(스펙 §9 "일정 질문과 기기 캘린더", §12 통제 2). 서버는 일정 기간(`schedule {from,to}`)만 돌려준다.
- 단, 네이버 캘린더 자체는 네이버 서버에 있다. 기본 캘린더를 네이버로 두면 ERURI가 추가하는 일정 제목·시각도 네이버로 간다(4절).
